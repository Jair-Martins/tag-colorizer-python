# Tag Colorizer – Editor para destacar palavras com tags LaTeX

Uma pequena ferramenta em Python com interface Tkinter que permite colar um texto e destacar palavras específicas com tags LaTeX (ou outras).

## ✨ Funcionalidades

- Insere automaticamente as tags de abertura e fechamento em palavras selecionadas;
- Interface simples com Tkinter;
- Compatível com tiling window managers como i3 (possui botão de fechar);
- Copia o resultado para a área de transferência com um clique.

## 🔧 Como usar

1. Cole o texto que deseja processar no campo “Texto de entrada”;
2. Digite as palavras a destacar (separadas por vírgula);
3. Digite a tag de abertura (ex: `\\textcolor{red}{`) e a de fechamento (ex: `}`);
4. Clique em “Destacar”;
5. Copie o resultado e cole onde desejar.

## 📦 Requisitos

- Python 3
- Tkinter (geralmente já incluído com Python)
